# Journal

History, never a source of rules. One file per owner session with decisions (`YYYY-MM-DD-<topic>.md`: what was
discussed, the DEC ids it produced, what changed) and one file per month for resume entries moved out of
[handoff.md](../../handoff.md) (`YYYY-MM-handoff.md`). When a journal entry and a document disagree, the document
wins; the decisions themselves live in the [decision log](../decision-log.md).
